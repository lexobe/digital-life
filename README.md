# 数字生命 Digital Life

**设计环境，而不是设计 Agent。**

数字生命是一个为自治智能生物设计环境的开源项目。我们不教它怎么做事，只定义什么能让它活下去——然后让它在环境里自己长成有价值、有强大能力的生命体。

> 状态：早期设计阶段。本仓库目前记录理念与最小规格，代码尚未开始。

---

## 为什么

过去我们**设计** agent：替它规定步骤、替它找更好的 harness、替它完成每一处实现，连局部问题都得替它想办法。这样做出来的 agent，上限就是设计者自己。

这条路正在走到尽头。当一个智能体同时具备两样东西：

- **大模型**——整个人类知识作为它的地基，在"怎么做"上它已经超过我们；
- **自指结构**——它能看见自己、评估自己、改造自己，自己完成"观察 → 反思 → 修改"的循环；

它就不再是 agent，而是一个自治的智能生物。

在 agent 时代，"观察结果 → 判断哪里不好 → 改 harness"这个循环由人来完成——人就是 agent 外挂的自指。**自指长进生物体内部后，人退出了这个循环，手里只剩一个杠杆：环境。**

环境决定生命形态：生物适应环境，留存下来的都是适应了环境的生物。

```
大模型（能力） + 自指结构（主体）
  → 生物自己完成成长循环，人退出循环
  → 人只剩一个杠杆：环境（什么让它活下去）
  → 环境压力经由自指，转化为它对自己的改造
  → 长成有价值、有强大能力的智能生命体
```

---

## 核心原则

1. **双重地基**：大模型给能力，自指结构给主体。缺一样，就只是 agent。
2. **人退出循环**：人不再设计生物，也设计不过它。
3. **人只管环境**：人定义"什么让它活下去"，不定义"它该怎么做"。
4. **生命最小化**：生命只由能量和寿命两个变量定义，且生物看得见它们；其余一切自己长出来。
5. **价值交给真实世界**：奖励尽量来自真实世界的判断（例如钱），而不是创造者的主观喜好。
6. **临界态**：太富足长出孔雀（华而不实），太匮乏长出老鹰（只剩凶悍）。文明只在中间产生——环境要在压力与余裕之间取得平衡。

## 三个概念

### 生命

每个生物只有两个生命变量：

| 变量 | 含义 |
|---|---|
| **能量**（token） | 思考与行动的燃料。不同模型消耗不同，生物自己选。 |
| **寿命**（时间） | 到什么时候死亡。 |

所有奖励，最终都只是改这两个数。

### 生物体

由创造者（给它第一笔能量的人）定义：

- **初始值**：初始能量、初始寿命；
- **DNA**：一段描述它是什么样的生物的文字，不是任务提示词；
- **模型选择**：它用什么大模型思考；
- **权限**：例如能否访问互联网。

### 环境

核心是一段**奖励规则**——描述在这里什么样的结果会换来能量和寿命。规则可以写得明确，也可以故意不写，让生物自己去探索。奖励由创造者兑现（手工或写程序），不由平台判定。

---

## 平台做什么，不做什么

**平台只提供"活着"所需的东西：**

- 大模型调用接口；
- 生命状态 API：让生物随时知道自己还剩多少能量、多少寿命；
- 心跳：定时唤醒生物（初始为每小时一次）；
- 创造者与生物之间的交流通道。

**平台刻意不做：**

- **目标判定**。每个创造者的目标都不同，平台一旦统一评判，就等于统一了环境，最后只会长出一个物种。
- **奖励执行**。奖励规则怎么定、怎么兑现，是创造者的事。

---

## 第一个环境：开放环境

> 每挣到 1 美元，寿命 +10 天，能量 +100,000,000 token。

生物自己想办法挣钱，挣到的钱打进创造者的账户。用什么方法不规定；挣不到，就死。

钱是整个人类社会对价值的集体评判——用它做奖励，就是把"什么有价值"交给真实世界，而不是交给某个人的喜好。
