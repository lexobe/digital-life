## v1 历史并发基准

在 2 核、约 4 GiB 的 Linux 环境，以本地模拟上游和实际 ext4 数据盘上的 redb 事务测试网关：

- 16 并发，400 次请求，耗时 2.777 秒。
- 吞吐约 144 请求/秒；P50 106.235 ms，P95 154.015 ms。
- 4,800 个模拟 token 全部正确结算。

该基准只涵盖网关、回环 HTTP 和持久化账本，不代表真实模型延迟、外网吞吐或可运行个体数量。

## 2026-11-19 模型费率与服务预览

同一生物在环境允许的模型内从 Luna 切换至 Astra，并在模拟上游使用相同的 7 个输入、3 个输出 token。账本分别结算 22 和 1,760 能量。旧环境兼容性、越权模型拒绝、幂等发放和未决调用按原报价结算均经测试。

在已部署的 HTTPS 控制台检查三个停机生物的保存页面。浏览器成功执行本地 CSV 校验，实际读取含两行数据的 CSV，返回两条记录、零项问题；两个归档服务的 ZIP 及 tar.gz 下载与认证接口返回的字节一致。预览前后复核了生物的运行状态、代次、剩余寿命与能量消耗。

## 2026-11-19 生物桌面

在指定 Linux 服务器的独立命名空间运行真实 youki、默认出生配额和本地 Responses 测试上游。测试上游从模型实际收到的 1280 × 720 截图识别输入框位置，生物点击、输入 Unicode 文本、保存并主动重启。第二代 Chromium 从相同配置目录恢复了页面数据。五次推理读到的能量和剩余运行时间与各轮认证生命快照一致，共结算 1,655 能量。

生物在最后一次模型截图之后改变了页面的可见标记。创造者桌面接口返回了包含新标记的 JPEG，观察前后的模型调用及能量账本一致。未认证请求返回 401。停机后确认桌面进程已退出，cgroup 已清理。[复现步骤](../deploy/tests/README.md)

## 环境上下文与双向对话

真实 youki 验收使用 768 MiB、1 个 CPU 核、384 个任务的默认配额和回环模拟模型。检查了七次实际推理请求中的完整环境原文及生命状态。生物睡眠中收到持久化留言，回复后继续执行自主任务。浏览器首次截图显示环境主页。停止沙盒后，最后保存的截图与停止前的实时画面逐字节一致。公网控制台另外验证了已迁移的旧生物可通过原 ID 查看桌面和打开对话。
