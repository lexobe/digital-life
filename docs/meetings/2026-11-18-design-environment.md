## 一句话核心

大模型加上自指结构，造出了一个在"怎么做"上超过人、并能自己完成成长循环的主体；从此人能给它的只剩环境，而环境决定它长成什么样。

---

## 核心原则（会后梳理，刘总确认）

### 因果链

```
地基 = 大模型（能力） + 自指结构（主体）
  → 生物自己完成"观察 → 反思 → 修改"的循环，人退出这个循环
  → 人只剩一个杠杆：环境（什么让它活下去）
  → 环境压力经由自指，转化为它对自己的改造
  → 长成有价值、有强大能力的智能生命体
```

### 范式转换

过去我们**设计** agent：替它规定怎么做、替它找更好的 harness、替它完成所有实现，连局部实现都要替它想办法。自治的智能生物出现后，我们不应该、也没有能力再去指导它：它的地基是大模型和全部人类知识。

在 agent 时代，"观察结果 → 判断哪里不好 → 改 harness"这个循环由人来完成，**人就是 agent 外挂的自指**。自指长进生物体内部后，人退出了这个循环。

| | 设计 Agent（过去） | 提供环境（未来） |
|---|---|---|
| 人的角色 | 工程师：规定步骤、找 harness、补局部实现 | 生态设计者：定义什么让它活下去 |
| 能力来源 | 人的设计 | 地基（大模型）+ 自身成长 |
| 上限 | 设计者的认知 | 地基 + 环境压力，可以超过设计者 |
| 人回答的问题 | 它该怎么做？ | 什么结果值得奖励？ |
| 出问题改哪里 | 改 agent | 改环境 |

### 六条原则

1. **双重地基**：大模型给能力，自指结构给主体。缺一样，就只是 agent。
2. **人退出循环**：自指由生物自己完成后，人不再设计它，也设计不过它。
3. **人只管环境**：人定义"什么让它活下去"，不定义"它该怎么做"。
4. **生命最小化**：只给能量（token）和寿命两个变量，并让它看得见这两个数，这是自指最起码的输入。
5. **价值交给真实世界**：奖励尽量来自真实世界的判断（如钱），少依赖创造者的主观喜好。
6. **临界态**：环境的压力和余裕要平衡。太富足长出孔雀，太匮乏长出老鹰，文明只在中间产生。

## 1. 从 Agent 到数字生命：LUCA 类比

- 今天所有的 AI 使用都是基于 agent 的，agent 本质是个代理、助手角色。
- 自指机制出来后，它变成独立生命体，可以理解为数字世界的 **LUCA**（Last Universal Common Ancestor，最后共同祖先），即生物界最早的那一个细胞。
- 有了这样一个东西之后的问题是：这个生命会长成什么样？答案几乎全由环境决定。

## 2. 环境决定形态：孔雀 vs 老鹰，文明只在临界态

- 资源极其充沛的环境（热带丛林）：长出非常漂亮的鸟，如孔雀，华而不实，在生存竞争上没有任何意义，只有"传承漂亮"。
- 资源极其匮乏的环境（北方）：长出极其凶悍的生物，如老鹰。
- **文明只在临界状态下产生**：既不能太好、太舒适（如东南亚，生存环境非常舒服、富庶），也不能太糟糕（如北方）。
- 推论：设计环境时要瞄准临界态，既不过度富足，也不过度匮乏。

## 3. 平台管什么、不管什么

### 平台要提供的

1. **大模型接口**：模型调用能力。
2. **统一的生命状态 API**：向生物反馈它的生命情况，只有两个数：还剩多少 token、还剩多少时间。
3. **心跳**：每个生物体一小时一次唤醒。
4. **交流通道**：创造者与生物之间的通道。

### 平��不提供的

- **奖励规则与奖励执行**：怎么定、怎么操作，是创造者自己的事，甚至可以手工做。例：创造者说"你赚到一美元，我就给你加"，前期明知它赚不到，赚到了手工加就好。
- **目标判定模块**：不在平台里做"判断是否符合目标再给奖励"的东西。每个创造者的目标都不一样，这件事做不好，应抽掉，交由创造者自管。

## 4. 奖励极简化：只有两个参数

| 参数 | 含义 |
|---|---|
| token（能量） | 生物的能量。不同模型花费不一样，生物体可以自己选模型；打仗时用更强的模型，花费更多。 |
| 时间（寿命） | 存活时间，到什么时候死亡。 |

- 奖励规则示例：**赚到 1 美元，token 增加 100,000,000，寿命增加 10 天**。数值为举例，会上先后说过 1 个月和 10 天两种讲法，统一按 10 天记录。
- 生存期内，生物体自己去努力；怎么奖励，写成文字给它。
- 奖励的兑现形式就是**直接加数据**（加 token 数、加时间）。

## 5. 环境 vs 生物体：两个东西，必须分开

### 环境

- 核心是**奖励规则**：一段文字，描述在这个环境中什么样的结果会得到奖励。
- 也可以写得不确定：不告诉它什么行为会得奖励，让它自己去探索。
- 奖励怎么实施是创造者的事（手动或写程序），与平台无关、与环境定义无关。
- 每个生物体都有创造者，即给它第一笔钱的那个人。

### 生物体

- 初始值：初始 token 数量、初始寿命长度；
- 访问权限：互联网访问等；
- 模型选择：属于生物体层面的特征，不是环境层面的；
- **初始 DNA 描述**：没有传统意义上的任务提示词，取而代之的是"你是一个比较严谨的……生物"这类核心描述。

## 6. 第一个环境：开放环境

- 名字：**开放环境**（初始环境）。
- 规则：每挣到 1 美元，得到 10 天寿命增加 + 100,000,000 token。
- 与量化交易系统的关系：生物体自己去挣钱，挣到的钱打到创造者的账号里（给它一个收款二维码）；人民币 1 块钱也算奖励。方法不管，挣不到就死掉。
- 实施：做最简化版本，今天的第一个目标就是把基础的东西跑起来。

## 与既有线的关系

- 这是 2026-11-13 立项的"临界态智能生物的构建"目标的新一层展开。此前 v1 结论讲的是 agent 与人的分工（agent 只写、思想是人的）与锚/收据机制；这次讲的是**生命形态由环境决定**，设计对象从 agent 转向环境，奖励收敛为 token + 寿命两个参数。
- 设计对象转向环境的根本原因是**能力反转**：大模型 + 自指结构让生物在"怎么做"上超过人，人只能、也只应提供环境。
- "临界态"一词在此获得第二层含义：除 agent 与人类信息交互的临界态外，环境本身也须处于"不太好也不太坏"的临界态，文明才可能产生。
